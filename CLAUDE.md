# Ionity Business Mind Map (IBMM)

Voice-first AI workspace (blueprint ION-ARC-NOTECAD-2026-001). The owner talks; the brain files each note on the
owner's own mind map as notes, tasks, alerts and progress, and delegates work by name. Everything runs on the
desktop WABAKIPI (Windows 11, RTX 4060), offline unless a Claude or Deepgram key is set.

## Start, stop, check

```powershell
cd E:\.claude\Ionity\.NoteCad
powershell -ExecutionPolicy Bypass -File services\start_notecad.ps1             # everything, then a green health table
powershell -ExecutionPolicy Bypass -File services\start_notecad.ps1 -Showcase   # ... and the showcase farm on the map
powershell -ExecutionPolicy Bypass -File services\start_notecad.ps1 -Status     # health table only
powershell -ExecutionPolicy Bypass -File services\start_notecad.ps1 -Stop
```

Phones and a second worker: `-Lan` (phones on the farm network over HTTPS on :9788, the brain's own certificate in
`data\brain\tls`, pinned by the phones; phone token in the vault, then **Pair a phone** in the app's status chip; once,
as admin: `services\allow_phones_firewall.ps1`) and `-EdgeNode` (an Edge AI Node sync hub on :8789, `data\edge-node`, synced with the brain).
Other switches: `-Ui dev` (Vite on :5173, hot reload), `-Ui desktop` (Tauri window, once built), `-Ui none`,
`-Rebuild` (force a UI build; it also rebuilds by itself when a source is newer than `dist`), `-NoOpen`.
The app opens at **http://127.0.0.1:8788/** (use 127.0.0.1 or localhost: other host names need the token).
Start-up is about 17-22 s; the script starts the companion and brain side by side and sets `OLLAMA_KEEP_ALIVE=-1`.

## Architecture

| Part | Where | Port | What it does |
|---|---|---|---|
| Ollama | `runtime\ollama`, models in `models\` | 11434 | Gemma 4 E2B (`notecad-gemma4-e2b`: router + companion) and EmbeddingGemma (`notecad-embeddinggemma`: retrieval). Signed, so it runs under Smart App Control; unsigned llama.cpp is blocked |
| Companion | `services\companion` | 8787 | Learns the owner (memory, reply style, per-owner LoRA); answers from the brain's digest and map lines; `context_node_id` for "this one" |
| Brain | `services\brain` | 8788 | Capture → Whisper (GPU) → split → candidates → router chain (Claude → Gemma → rules) → validate → apply (one transaction, inverses for Undo) or Inbox. SQLite at `data\brain\brain.db`. Serves the UI at `/app/` |
| Desktop app | `apps\desktop` | 8788/app, 5173 dev | React 19 + Vite 8 + Tailwind 4 + React Flow 12 + TypeScript 7: recorder pill (hold Space, `/` to type), live status from SSE, toast with Undo and branch pills, **foldable** mind map (d3-hierarchy tidy tree), node drawer with history and voice playback, sync chip. `src-tauri` is the transparent always-on-top window (Ctrl+Shift+Space) |
| Core | `packages\core\src` | | Framework-free logic shared by both apps: `fold.ts` (which nodes are on screen) |
| Edge AI Node | `services\brain` (`-Name edge-node -HubOnly`) | 8789 | Another brain used as sync hub; on a farm-office PC it can run the full stack |
| Phone app | `apps\mobile` | 5174 dev | Capacitor 8 (Android APK; iOS needs a Mac). Outbox in IndexedDB / native files, tus uploads, Android capture bubble, iOS Action Button intent |
| Supabase | `supabase\migrations` | | Same schema + RLS for the cloud (0001 core, 0002 capture anchor, 0003 sync readiness, 0004 sync journal, 0005 sync hardening (generated by `tools\gen_sync_migration.py`), 0006 indexes, 0007 roles (frozen), 0008 device lookups + RLS, 0009 retention and privacy notice (0009 generated from `db.py` and `permissions.py` by
`tools\gen_rls_migration.py`; 0007-0008 frozen by hash)) |

Key brain endpoints (all also under `/api/v1`): `POST /v1/workspaces/{ws}/capture` (multipart audio or text,
`context_node_id`), `GET .../mindmap`, `GET .../events/stream` (SSE with `Last-Event-ID`), `GET .../digest`,
`GET /v1/nodes/{id}/history`, `POST /v1/captures/{id}/undo`, `POST /v1/inbox/{id}/resolve`, `GET .../sync`,
`GET .../export`, `DELETE /v1/workspaces/{ws}?confirm={ws}`, `POST .../uploads` (tus 1.0.0 for phones),
`GET /v1/pairing` (this PC only), `GET /v1/sync/status`, `POST /v1/sync/push`, `GET /v1/sync/pull`, `POST /v1/sync/ack`,
`POST /v1/sync/now`, `GET /v1/captures/{id}/audio` (the recording, for playback). Roles (ADR 0014): `GET .../me`
(role and capabilities), `.../members`, `.../audit`, `.../seats`, `.../invites`, `.../devices`, `POST /v1/nodes/{id}/visibility`,
`GET|POST /v1/join` (an invite code; gives the phone its own `nct_` token), `PATCH /v1/members/{id}`,
`POST /v1/members/{id}/revoke`, `GET /v1/device/snapshot|pull`, `POST /v1/device/wiped`. POPIA: `POST /v1/tickets`
(a 10-minute `?ticket=` for EventSource and `<audio src>`: never a token in a URL), `GET|PUT .../privacy`,
`POST .../privacy/ack`, `POST .../retention/run`, `GET .../subjects/{id}/export` (one person's copy, s23),
`POST .../subjects/{id}/erase?confirm={id}` (an owner, s24), `POST /v1/join/preview` (the invite code in the body).

Schema changes: numbered and forward-only, `MIGRATIONS` in `notecad_brain\db.py` (recorded in `schema_migrations`)
with the same number as the Supabase file; a test keeps them in step.

Sync (ADR 0012): triggers write every change to `sync_changes`; last writer wins per row; `action_log.synced_at`
is set once a peer has the row. Target in the vault: `NC_BRAIN_SYNC_TARGET=http://<edge-node>:8789` or
`postgresql://...` (Supabase), `NC_BRAIN_SYNC_TOKEN` for a remote node. Off this PC every request needs
`NC_BRAIN_API_TOKEN`; this PC (loopback) does not. Diagram: `docs\notecad_data_flow.html`
(artifact "IBMM Capture Flow"). Decisions: `docs\adr\0007`-`0014`. Phase 6: `docs\plans\PHASE6.md`,
numbers in `docs\perf\`, build history in `docs\BUILD_STATUS.md`.

Roles (ADR 0014): owner 1, manager 2, employee 3 (system 0); `notecad_brain\permissions.py` holds the matrix and the
View. The caller is worked out from the credential only: a phone's `nct_` token (stored hashed; revoked: 410 with
`wipe`), the shared token (the first owner while `NC_BRAIN_LEGACY_TOKEN_OWNER=1`, for one release), this PC (the first
owner, or `NC_BRAIN_LOCAL_MEMBER`; on a shared PC set `NC_BRAIN_TRUST_LOOPBACK=0`). Restricted branches inherit down
(`eff_level`); reads go through the caller's view, writes through `Applier.judge` (allowed, Inbox proposal, or refused
and logged), sync re-checks the author's current role. Seats are a local ledger (no billing provider; ask the owner
before choosing one). Employees may not create child nodes (ask the owner before changing that).

POPIA (`docs\compliance\`, review of 29 October 2026): the brain runs as `python -m notecad_brain.serve` (plain HTTP on
loopback only; `--lan` adds HTTPS on Port + 1000 with `tls.py`'s certificate, its SHA-256 in the pairing QR and invite
links as `f=`, pinned by Android's `TlsPin`; another brain pins a LAN hub with `NC_BRAIN_SYNC_CA=<hub cert.pem>`). The
log is `data\<name>\logs\api.log`, weekly, 4 weeks kept, tokens / tickets / invite codes blanked. `retention.py`: an
owner sets how long recordings, transcripts and the activity log are kept in the privacy notice (nothing is deleted
until then); the worker purges every 6 hours and compacts the sync journal to the newest change per row; deleting a
workspace leaves only data-less tombstones. `NC_BRAIN_ARCHIVE_DAYS` ages out `data\archive` (unset: kept). The privacy
notice (`privacy.py`, desktop `PrivacyNotice.tsx`, phone `PrivacySheet.tsx`, version 2) opens until the owner accepts
it and each member has read it; a member's capture is refused (`privacy_unread`) until then. The cloud transfer gate
(`privacy.cloud_ok`, the owner's tick in the notice) is off by default: Claude and Deepgram are skipped, and a note about
a restricted branch never leaves. `subjects.py` exports and erases one person. `text.sensitive_about` holds a worker's
health or disciplinary details for the owners. The phone token lives in the Android Keystore (`TokenVault`). Every
action on personal information is in `docs\compliance\popia-action-register.md`, generated by
`tools\popia_inventory.py` (`--check` in CI); what needs a person is in `popia-human-actions.md`; breaches:
`breach-runbook.md`.

Routing details (ADR 0013): Gemma sees short labels (n1, n2 ...) not node ids; plain field-work reports the rules are
sure of skip the model (`rules:sure`; `NC_BRAIN_RULES_FAST_PATH=0` turns it off). Map fold state is view state in
`localStorage` (`notecad.fold.<ws>.<layout>`), never synced; `localStorage notecad.layoutEngine=dagre` brings back
the old layout engine. Speech: the apps send no language hint, so Whisper picks the likeliest of
`NC_BRAIN_STT_LANGUAGES` (default `en,af`; empty: any language), and the keyterm prompt is written in the picked
language (`WhisperSTT.PROMPTS`). FLEURS Afrikaans WER: turbo 34.7 %, large-v3 32.2 % at twice the time
(`NC_BRAIN_WHISPER_MODEL=large-v3`, already in `models\whisper`); English 6.1 / 2.8 % (`docs\perf\afrikaans-wer.json`).

CI (`.github/workflows/ci.yml`, GitHub Actions on every push; the repo is public, so it is free): brain + companion on
SQLite and Postgres 17, Supabase 0001-0009 on an empty database (0007-0009 run twice), `gen_rls_migration --check`, the debug APK + Android unit tests, `cargo check`
and unsigned Tauri installers. The APK and installers are artifacts of each run. Step logs need a GitHub sign-in; the
test counts are notices on the run page, and a failing Android build or test writes its cause there too. This is how
Postgres, Android and Tauri get tested: none of them can be built on this PC (no Postgres, nothing on C:, Smart App
Control). Android JVM tests (`app\src\test`, Robolectric 4.17) need the `--add-exports` flag in `app\build.gradle`.

## Windows gotchas on WABAKIPI

- Scripts: `powershell -ExecutionPolicy Bypass -File ...` (script execution is off). Use `npm.cmd`, not `npm`.
- `NODE_ENV=production` is set machine-wide: `npm.cmd ci --include=dev` or the UI build tools are skipped.
- The venv `python.exe` is a launcher with a child process: stop services by command line, not by PID.
- Windows PowerShell 5.1 hands back a JSON array from `Invoke-RestMethod` as one object: pipe through
  `ForEach-Object { $_ }` before counting.
- faster-whisper needs PyAV below 16 (`av>=14,<16`). CUDA comes from the `nvidia-cublas-cu12` / `nvidia-cudnn-cu12`
  wheels in the brain venv (the brain adds their DLL folders); without them Whisper falls back to the CPU.
- Python 3.14 lives at `C:\Python314` (base interpreter only); the venvs are under `services\*\.venv`.
- `start_notecad.ps1` runs the edge node and the brain in one PowerShell session: `start_brain.ps1` must reset
  every per-instance env var (`NC_BRAIN_WORKER`, `NC_BRAIN_STT`, `NC_BRAIN_SYNC_TARGET`) or the hub's settings leak.
- Windows takes about 2 s to refuse an HTTP connection to a loopback port nothing listens on: probe the port with a
  short TCP connect first (`Test-Port` in the scripts).
- Playwright uses the installed Edge (`channel: 'msedge'`): no browser download. Laptop panels switch between 60 and
  144 Hz; compare frame rates with the idle rate of the same run.
- Leave the DGMic account alone.
